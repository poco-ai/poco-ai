# 双链

正文写 `[[目标]]`。索引只有 `blog` 和 `shorts`。匹配顺序是集合内路径、文件名、frontmatter 的 `title`。同一键有多篇时对不上。对不上的字还在，只是不能点。生产构建不索引 `draft: true` 的稿子。

```md
[[cards]]
[[2026/10/新的起点]]
[[卡片用法]]
[[cards|卡片那篇]]
[[卡片用法#歌曲]]
[[#别名]]

这段给块链接用。 ^sample

[[双链^sample]]
[[^sample]]
```

- 文件名不带 `.md`。文章在 `年/月` 子目录里时，文件名唯一就可以只写文件名。
- 路径从集合目录算起，例如 `2026/10/新的起点`。也可以写成 `blog/2026/10/新的起点`。
- `|` 后面是显示文字。
- `#` 后面是那一节的标题，按页面上的标题文字匹配。同一篇可以只写 `[[#标题]]`。
- 段落末尾空一格，再写 `^标识`。标识只用字母、数字、下划线和连字符。`[[篇名^标识]]` 链到那一段；同一篇里写 `[[^标识]]`。
- 被链到的文章文末列出链过来的篇目。发出这些链接的这篇，文末没有那份列表。
- `\[\[这样]]` 原样显示，不生成链接。

完整例子在 `src/content/shorts/wikilink.md`。
