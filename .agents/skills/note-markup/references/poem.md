# 诗

`:::poem` 夹在段落之间。开围栏占一行，单独一行的 `:::` 结束。围栏里面不能再写 `:::`。

```md
:::poem{title="目光" subtitle="其一" date="2024.3" place="杭州"}
> 题记。*瞳仁* 是着重号。

一行一句
空行另起一节

[^1]: 注释放在诗的末尾。
:::
```

- `:::poem[目光]` 和 `title="目光"` 一样。两处都写时用属性里的标题。
- `date` 和 `place` 排在右下，像 `2024.3 · 杭州`。
- 开头连续的 `>` 是题记。写了块引用就用它。`epigraph` 只在没有 `>` 时使用。
- 一行一句。空行分节。`*字*` 是着重号。要显示出星号或反斜杠，写成 `\*`、`\\`。
- 写了 `vertical` 就是竖排。`vertical=false`、`vertical=0`、`vertical=no` 仍是横排。
- 同一 `series` 的几首必须紧挨着，中间不能夹段落，否则组会断开。组题只出现一次。

```md
:::poem{series="夜色两则" title="其一" date="2024.3" place="杭州"}
第一首
:::

:::poem{series="夜色两则" title="其二" date="2024.6" place="上海" vertical}
第二首里的*着重号*
:::
```

诗题不进目录。诗里的 `[^id]` 只属于这首诗，编号按注释出现的顺序。围栏外面的脚注仍是文章脚注。
